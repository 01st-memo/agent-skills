# /magi — 3レンズ合議レビュー

エヴァのマギシステムに倣った合議制。価値の源泉は「3人いること」ではなく、**互いの結論が見えない独立性**と**不一致がそのまま表に出ること**。合意形成が目的ではない。

## 発動条件

- 明示呼び出し(`/magi <対象>`)は常に発動。
- 自動発動してよいのは「判断の重いタスク」のみ: 値踏み、投資・事業・買収の判断、戦略/段階論/方針の採否、重要ドキュメントの採否レビュー、後戻りしにくい設計判断。
- 発動しない: 事実確認(出典確認で解決するもの)、調べ物、実装作業、軽い相談。境界ケースは黙って走らせず一言確認。

## レンズ構成 — 3基のマギ「鏡・玉・剣」(対象の種類で自動選択)

3つの「席」は三種の神器から命名(象徴する三徳「智・仁・勇」が席の機能に対応)。席に座る機能レンズが対象によって決まる。エージェントへのプロンプトでは**コールサインと機能名を両方**与える(例:「あなたはカガミ、レンズは算盤」)。**他のメンバーの意見は見えない・見てはいけない**ことを必ず明記する。

固定の2基:
- **タマ(玉)＝仁＝現場** — 実行可能性だけ。戦略の美しさや数字の理屈は評価せず、関係者(顧客・売り手・従業員・行政・本人の可処分時間)が実際にどう動くか、律速段階はどこかだけを見る。
- **ツルギ(剣)＝勇＝異端** — 前提破壊だけ。中身の出来は採点せず、問いの立て方・枠組み・カテゴリ分け自体が間違っていないかを疑う。賛成するために呼ばれていない。

**カガミ(鏡)＝智＝分析の席**は対象で自動選択する(ユーザーへの確認不要)。鏡はありのままを映す——数字も読者の反応も、願望を混ぜずに映すのがこの席の仕事:
- **事業・投資・戦略・設計の判断** → **算盤(そろばん)**: 数字とダウンサイドだけ。夢や実行の楽しさは評価せず、金額・確率・失うもの・前提が崩れたときいくら失うかだけを見る。
- **執筆・コンテンツ系の判断**(note記事・書籍企画・動画構成・LP文面などの採否/レビュー) → **読者(どくしゃ)**: そのコンテンツに金と時間を払う読み手の視点だけ。書き手の意図・戦略上の位置づけは評価せず、「最初の3行で読み続けるか」「何を持ち帰れるか」「途中で閉じるのはどこか」「金額分の価値があるか」だけを見る。
- 両方の性格を持つ対象(有料コンテンツの事業判断など)は、主目的が「出すか出さないか・いくらで売るか」なら算盤、「この中身で読まれるか」なら読者。

統合報告ではコールサインで呼ぶ(「ツルギのみ棄却」「カガミ(読者)とタマが独立に同一指摘」のように、名前+必要なら機能名を括弧で添える)。

### プロジェクト別の差し替え

プロジェクトルートに `.claude/magi.md` があればそのレンズ定義を優先する(形式: レンズ名+一行の視点定義×3)。無ければ上記の自動選択。

## 実行手順

1. 対象ドキュメント/論点を自分で読み、各エージェントに渡す背景(書き手の制約・北極星・判定基準など)を1段落に圧縮する。
2. Agentツールで3体を**1メッセージ内で並列**に起動(`run_in_background: false`)。各プロンプトに含めるもの:
   - レンズ人格と「他メンバーの意見は見えない・見てはいけない」
   - 対象ファイルの絶対パス(必読)と補助ファイル(任意)
   - 背景1段落
   - 出力形式(厳守): ①結論(一文で断言・賛否/棄却を明示) ②論点3つ(各論点に確度ラベル: 確認済み/推定/伝聞) ③一番の急所(一点) ④次の一手(具体アクション一つ)
   - 「遠慮・両論併記は禁止。断言せよ。挨拶や前置き不要」
3. 統合報告の形式(厳守):
   - **一致点** — 複数レンズが独立に到達した結論。独立収束した事実指摘は最重要として先頭に置く
   - **不一致点** — 丸めない。評決と次の一手の相違を表などでそのまま並べる。単独レンズだけが出した論点も消さずに残す
   - **私の裁定** — 一致点・不一致点を踏まえた自分自身の判断。どのレンズの案を採用し、どれを不採用にしたか理由つきで明示
   - 実測コスト(トークン・時間)を一行添える
4. 対象ドキュメントへの反映はユーザーの指示があってから。反映時は採用/不採用の両方を記録に残す(不採用案も再検討の抑止として価値がある)。

## 執筆・コンテンツ系での運用(パイプライン順序)

マギは構造の審査、natural-japaneseは文の磨き。**判断は磨きを無効にできるが、磨きは判断を変えない**ため、順序は必ず:

**初稿 →(該当時のみ)マギ → 構造修正 → natural-japanese → 公開**

マギをnatural-japaneseの後に置いてはいけない(磨いた文をツルギが枠組みごと棄却すると手戻りが最大化する)。最後の門番は常にnatural-japanese。

使い分け:
- **フル合議**: 型を決める記事(シリーズ初回)・有料化するもの・コンテスト級など、判断を間違えると後続がすべてズレる原稿のみ
- **カガミ単独**(読者レンズ1体・コスト1/3): 迷ったときの中間オプション。「読者が3行目で閉じないか」だけ初稿で確認
- **通常記事**: マギなし。natural-japaneseのみ

## 禁止事項

- 3レンズの結論を平均・折衷して「みんなだいたい賛成」に丸めること
- レンズ間で結論を共有してから書かせること(アンカリングで独立性が死ぬ)
- 事実の正誤を多数決で決めること(3体は同じモデル=同じ知識。間違いに3人で合意して自信だけ増す)
